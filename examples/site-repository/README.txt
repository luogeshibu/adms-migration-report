Site Repository example

Choose the parent directory (the directory that contains ADF/ABH/ABN2) in the application.
Each site should use these standard filenames when possible:

SE.xlsx
ZENON.XML
ZENON-DB.csv
ZENON-SLD.csv
ADMS-DB.csv
ADMS-SLD.csv
ZENON-ADMS-IOA.csv

See docs/SITE_REPOSITORY.md.

STANDARD reference is bundled with the application as resources/templates/IOA STANDARD.xlsx; do not place a REPORT workbook in site folders.
